## Run Jest Tests

1. In terminal

```
npm install
```

2.

```
npm run test:jest
```

## Run Postman Tests

0. Open 2 terminals from this demo folder

1. in terminal 1

```
npm run start
```

3. in terminal 2

```
npm run test:postman
```

## Import Postman Collection

1. Click **Import** button (top left)
2. Drag and drop `API-Testing-Postman.postman_collection.json` or click **Upload Files**
3. Click **Import**
